Anthropic Agent Skills 官方标准： Level 1 (YAML frontmatter) 始终预加载 → Level 2 (Markdown instructions) 按需激活 → Level 3 (Resources) 实际使用时加载

💡 无关键字匹配，由 AI 基于 description 自主判断相关性 | ✅ 标准 SKILL.md 格式，完全符合 Anthropic 官方规范

新建技能

唯一标识符，使用小写字母和下划线
一级技能可被AI直接加载；二级技能通过父技能引用加载
二级技能必须指定一个父技能
Level 1 元数据，用于 AI 判断是否需要加载此技能
Level 2 内容，当技能被激活时会加载到 AI 的上下文中
💡 如何引用子技能？

在详细指令中使用 @use:子技能名称 来引用子技能，例如：@use:sql_payload_generator

勾选后此技能会始终包含在 AI 的上下文中（仅限一级技能）
